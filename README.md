# 조모임 랜덤 질문 100

조모임이나 소그룹 활동에서 사용할 수 있는 아이스브레이커 질문 생성기입니다. 100개의 다양한 질문을 카테고리별로 랜덤하게 뽑을 수 있습니다.

## 기능

- **랜덤 질문 뽑기**: 버튼 클릭으로 질문을 랜덤하게 선택
- **카테고리 필터링**: 원하는 주제의 질문만 선택 가능
- **질문 공유/복사**: 현재 질문을 쉽게 공유하거나 복사
- **전체 목록 보기**: 선택된 카테고리의 모든 질문 확인
- **자동 재섞기**: 모든 질문이 나오면 자동으로 다시 섞임

## 카테고리 (100개 질문)

- **서로 알아가기** (10개) - 일상, 성격, 취향
- **음식/취향** (10개) - 음식 관련 질문
- **취미/여가** (10개) - 여가 활동, 취미
- **TMI** (10개) - 가벼운 개인 정보
- **신앙/교회** (10개) - 신앙 생활 관련
- **가치관/꿈** (10개) - 가치관, 목표, 꿈
- **상상/게임** (10개) - 가상 상황 질문
- **가족/관계** (10개) - 가족, 친구 관계
- **경험/추억** (10개) - 과거 경험, 추억
- **마무리** (10개) - 모임 마무리용 질문

## 사용 방법

1. 웹 브라우저에서 [index.html](index.html) 파일을 엽니다
2. 원하는 카테고리를 선택합니다 (기본값: 전체)
3. "랜덤 뽑기" 버튼을 눌러 질문을 확인합니다
4. 필요시 질문을 공유하거나 복사합니다

## 파일 구조

```
icebreak-questions/
├── index.html          # 메인 HTML 페이지
├── style.css           # 스타일시트
├── questions.js        # 질문 데이터 (100개)
├── script.js           # 메인 로직
└── README.md           # 프로젝트 설명
```

## 기술 스택

- HTML5
- CSS3 (반응형 디자인)
- Vanilla JavaScript (프레임워크 없음)
- 오프라인 사용 가능

## 주요 기능 설명

### 랜덤 뽑기

- Fisher-Yates 알고리즘을 사용한 질문 섞기
- 중복 없이 모든 질문이 나올 때까지 진행
- 모든 질문이 나오면 자동으로 재섞기

### 카테고리 필터

- 여러 카테고리 동시 선택 가능
- 최소 1개 카테고리는 항상 선택 상태 유지
- 필터 변경 시 즉시 질문 풀 재구성

### 공유 기능

- Web Share API 지원 (모바일)
- 미지원 브라우저에서는 클립보드 복사로 대체
